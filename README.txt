AI MUSIC SAMPLE LAB
===================

프로젝트 목적
-------------
Suno에서 원하는 음악 방향을 찾기 위해 반복 생성하며 크레딧을 사용하는 대신,
짧은 음악 샘플을 먼저 비교하고 선택한 아이디어만 본 제작으로 발전시키는
사용 흐름을 표현한 웹 프로토타입입니다.

과제 조건
---------
- HTML, CSS, Vanilla JavaScript만 사용
- 외부 프레임워크, 라이브러리, CDN, npm 패키지 미사용
- 여러 페이지로 구성
- 별도 서버나 백엔드 없이 브라우저에서 실행

페이지 구성
----------
1. index.html
   프로젝트 소개, 문제 정의, 4단계 워크플로와 아이디어 도출 흐름

2. sampler.html
   장르와 세부 장르, 샘플 유형, 생성 개수를 선택해 15초 데모를 생성합니다.
   Canvas 파형, 재생/정지, WAV 다운로드, 즐겨찾기, 기록 저장을 지원합니다.

3. history.html
   브라우저에 저장된 기록을 전체/즐겨찾기/장르별로 확인하고 관리합니다.

4. about.html
   프로젝트 아이디어 도출 배경과 사용 기술을 소개합니다.

실행 방법
---------
index.html을 Chrome 또는 Edge에서 열면 됩니다.
인터넷 연결이나 개발 서버가 필요하지 않습니다.
오디오 재생은 사용자가 PLAY를 눌러야 시작됩니다.

기술 및 동작 안내
-----------------
샘플 오디오는 JavaScript Web Audio API로 생성한 데모 톤/리듬이며,
Canvas API로 파형을 표시합니다. 생성한 샘플 메타데이터와 즐겨찾기는
현재 브라우저의 localStorage에 저장됩니다. WAV 파일은 브라우저에서
생성하여 다운로드합니다.

이 프로젝트는 실제 YuE2 AI 모델을 브라우저에서 실행하지 않습니다.
HTML/CSS/JavaScript만으로 기존 YuE2 기반 15초 Sample Lab의 사용 흐름과
아이디어를 시연하는 프로토타입입니다.

아이디어 도출
------------
AI 음악 생성 프로그램인 Suno가 음악을 만드는 방식이 궁금해 직접 사용했습니다.
원하는 결과를 찾으려고 여러 번 생성할수록 크레딧이 계속 소모되는 점이 아쉬웠습니다.

이후 로컬 환경에서 음악을 생성할 수 있는 YuE2를 알게 되었습니다.
완성도는 상용 서비스보다 낮을 수 있지만, 생성 크레딧 없이 여러 아이디어를
시험할 수 있다는 점에 주목했습니다.

YuE2를 완성곡 제작보다 약 15초 길이의 샘플을 여러 개 생성하는 용도로 활용하고,
마음에 드는 음악 방향만 Suno에서 발전시키면 불필요한 생성과 크레딧 소모를
줄일 수 있다고 생각해 이 프로젝트를 기획했습니다.
